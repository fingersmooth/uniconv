3. Pause et liste noire

Le raccourci : appuyez sur Alt + Maj + U. Tous les soulignements doivent disparaitre, l’icone doit afficher OFF, et plus aucune bulle ne doit apparaitre au survol. Appuyez a nouveau : tout revient.

Le popup : cliquez sur l’icone. Un bloc Detection affiche l’etat et propose de suspendre ou de reactiver. Le meme bouton sert aux deux sens.

La liste noire : les boites mail, les editeurs de code et les agendas (mail.google.com, github.com, notion.so...) ne sont jamais analyses. Cette page de test n’est pas concernee : vous devez donc voir fonctionner la section 2.

Verifier la liste noire sans quitter cette page

La liste noire est un reglage. Pour l’essayer, il faudrait ouvrir une adresse reellement exclue (par exemple github.com) et constater qu’aucun montant n’y est souligne. Le test automatique couvre deja ce cas : node tools/dynamic-tests.mjs.

Ou voir le detail : ouvrez le popup apres avoir charge cette page. La ligne Derniere page analysee indique combien de nombres ont ete ecartes, et pourquoi (« 9 nombres ecartes : numerotations, versions, dates… »).
